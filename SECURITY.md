# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in Partners, please **do not open a public issue**.

Instead, please send an email to **limmytian@gmail.com** with details about the vulnerability and steps to reproduce. We will acknowledge receipt of your report within 48 hours and provide updates on remediation progress.
